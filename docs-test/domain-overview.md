# Domains

**SPOKE** is a composable robotics ecosystem engineered to remove the traditional barriers of robot development. **SPOKE** provides both the interfaces that enable composition AND the verification that ensures it works. Every component is designed for interoperability across mechanical, electrical, and computational domains, enabling rapid assembly, modification, and scaling of robotic systems.

Building a robot requires verified integration across these three domains:

### **1\.** [**Mechanical**](/test/docs/domain-mechanical) 

> **Interfaces:** Standardized mounting patterns, screw placements, connector locations  
> **Assembly:** Pre-verified clearances and alignment. Parts screw together without custom brackets or surprises  
> **Verification:** Fit, structural integrity, kinematics validated

### **2\.** [**Electrical**](/test/docs/domain-electrical)

> **Interfaces:** Standardized connectors, power rails, communication buses, cables  
> **Assembly:** Plug-and-play connections with pre-routed cable paths. No custom wiring harnesses to design  
> **Verification:** Power distribution, signal integrity, EMI tested together

### **3\.** [**Computational**](/test/docs/domain-computational)

> **Interfaces:** Standard APIs, communication protocols, data formats; AI model interfaces for perception, control, and decision-making  
> **Assembly:** Auto-discovery and configuration. Software recognizes what's connected; pre-trained models load automatically based on hardware configuration  
> **Verification:** Timing, drivers, system integration pre-validated; AI models tested against hardware sensor suites and actuator capabilities
